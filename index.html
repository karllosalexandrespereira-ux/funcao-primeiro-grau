Aprendendo funções do 1º grau

Uma função afim é expressa por f(x) = ax + b, com a e b números reais. Quando a ≠ 0, ela é uma função polinomial do 1º grau, cujo gráfico é uma reta não horizontal.

1. Coeficientes
Em f(x) = 2x + 3, temos a = 2 (coeficiente angular) e b = 3 (coeficiente linear). O gráfico passa pelo ponto (0, 3).
2. Calculando valores
Para f(x) = 2x + 3, se x = 4, então f(4) = 2 · 4 + 3 = 11.
3. Raiz ou zero da função
É o valor de x para o qual f(x) = 0. Em 2x + 6 = 0, obtemos x = −3. Se a ≠ 0, a raiz é x = −b/a.
4. Crescente e decrescente
Se a > 0, a função é crescente. Se a < 0, é decrescente. Se a = 0, a função é constante e não é de 1º grau.
5. Construindo o gráfico
Marque dois pontos, como (0, b) e (1, a + b), e trace a reta que passa por eles. Use a aba Explorar gráfico para observar as mudanças.
6. Situação do cotidiano
Uma corrida de aplicativo cobra R$ 6,00 fixos e R$ 2,00 por quilômetro. O custo é C(x) = 2x + 6. Para 5 km, C(5) = R$ 16,00.
